## 🚨 Критические требования (Автотесты и ревью)
*Без соблюдения этих требований проект не пройдёт автоматическое тестирование.*

### Отображение в браузере
- [ ] Проект визуально соответствует макету: все секции, блоки и элементы корректно отображаются в Firefox, Google Chrome или Yandex Browser.
- [ ] Отличие от макета не более 10% (для системы скриншот-проверки).
- [ ] Отличие не более 5px по вертикали и 3px по горизонтали (для проверки ревьюером).
- [x] Использовать плагин Pixel Perfect для доводки вёрстки.
- [ ] Сетка макета не сбита (при сжатии страницы сохраняется расположение элементов, содержимое не выпадает за пределы блока, блоки не наезжают друг на друга).
- [ ] Отсутствует горизонтальная прокрутка и другие лишние полосы прокрутки при ширине экрана >= минимально допустимой.
- [x] Свёрстаны состояния `:hover` и `:active` для интерактивных элементов.

### Рекомендации к текущему проекту (Функциональность и позиционирование)
- [ ] Вёрстка не вредит функциональности JS:
  - [x] Карточки появляются во всех предусмотренных ситуациях.
  - [ ] Работают прелоадеры и заглушки ошибок.
  - [x] Работает поиск.
  - [x] Видеоролики подставляются в основной блок по клику.
- [ ] `position: absolute` в CSS используется **только** для блока `.visually-hidden`.
- [x] Остальной лейаут выполнен с применением гибких раскладок (flex/grid).
- [x] Изображения и видео подогнаны под заданные размеры через `object-fit`.
- [x] Состояния выбранных чекбоксов реализованы через псевдоэлементы.
- [x] Подчёркивание у кнопок и чекбоксов появляется при наведении на всю активную зону (включая сам чекбокс), а не только на текст.

- [x] Каждое правило начинается с новой строки.

- [x] Закрывающие скобки вынесены на отдельную строку.

- [x] Отсутствует слитное написание слов.

- [x] Нет транслитерации и необщеупотребительных сокращений.
- [x] Использованы имена классов из брифа (если применимо).

- [x] У `body` и типовых элементов сброшены браузерные отступы.
- [ ] Для всех элементов корректно заданы: цвета фона, размеры, межстрочные и межбуквенные расстояния, расстояния между словами (при необходимости).
- [x] Шрифты подключены в правильном порядке (от современных к старым с указанием формата).
- [x] Указаны альтернативные шрифты.
- [ ] Семейство, вес, начертание и размеры шрифтов соответствуют макету.

### Лейаут и позиционирование
- [x] Для организации лейаута ключевых блоков использован `flex` или `grid`.
- [x] Корректно отцентрированы необходимые элементы.
- [ ] Не задана фиксированная высота/ширина там, где можно использовать `min`/`max` или гибкость (блок должен растягиваться при добавлении текста).

- [x] Нет дублирующихся селекторов.
- [x] Нет дублирующихся свойств внутри CSS-правил.

- [x] Не используются инлайновые стили в HTML.

## ✨ Хорошие практики (Рекомендуется для портфолио)
*Необязательны для сдачи, но улучшают качество кода.*

### HTML и разметка
- [ ] В разметке нет лишних обёрток `<div>`.
- [x] У ссылок нет пустых атрибутов `href`.
- [x] У всех изображений задан атрибут `alt` с описанием на языке страницы.
- [x] Всем изображениям заданы ограничения размеров.
- [ ] Элементам не добавлены классы, которые не используются.
- [x] В стилях не указаны неработающие свойства (например, размеры для строчных элементов).

### CSS и геометрия
- [x] Для всех элементов переопределено дефолтное значение `box-sizing`.
- [x] Внутренние отступы задаются через `padding`.
- [ ] Нет лишних отступов у первых и последних элементов в списках и блоках с абзацами.
- [ ] Flex/grid не применяются без необходимости.
- [x] Для отступов между элементами использован `gap` вместо `margin`.
- [ ] Нет чрезмерной стилизации (например, дублирование размеров для обёртки и картинки).
- [x] Интерлиньяж задан в относительных единицах.
- [x] В элементах формы используются `inherit` или `currentColor`.
- [x] Для предсказуемого поведения инпутов использован `appearance: none;`.
- [x] Вместо `overflow: scroll` использован `overflow: auto`.
- [x] Вид курсора меняется при наведении на интерактивные элементы.
- [x] Для позиционирования изображения задано `object-position` вместе с `object-fit`.
- [ ] Для стилизации интерактивных элементов используется `outline`, а не `border`.
- [ ] CSS-правила расположены в примерном соответствии с позицией элементов в DOM.

### Доступность и состояния
- [x] Для стилизации используются только селекторы классов, псевдоэлементов и псевдоклассов (кроме сбросов).
- [x] Все элементы доступны при навигации с клавиатуры и визуально выделены (`:focus` и `:focus-visible`).
- [x] Учтены особенности `:focus` и `:focus-visible` (например, в `:focus-visible` у элементов формы лейбл обводится, а в `:focus` — нет).

### БЭМ (если используется в проекте)
- [x] Единообразное разделение имён блоков, элементов и модификаторов.
- [x] Элемент не используется вне своего блока.
- [x] Нет элементов элементов (например, `block__elem1__elem2`).
- [x] Класс модификатор не используется без указания блока или элемента.
- [x] Классы модификаторы описывают только модифицированное значение.
- [x] Внешняя геометрия блоков задана через миксы.
