# ⚠️ Требования к проекту (Чек-лист перед сдачей)

## 🛑 Работа отклоняется от проверки ревьюером (Критические ошибки)
*Пока эти пункты не исправлены, работа не будет принята на проверку.*
- [ ] Убедиться, что присутствуют все элементы макета (отсутствие 5+ элементов недопустимо).
- [ ] Проверить наличие всех секций макета.
- [ ] Соблюсти порядок блоков в точном соответствии с брифом.
- [ ] Исправить все критические замечания с предыдущих итераций (если есть).
- [ ] Убрать из кода/комментариев любые вопросы или просьбы о помощи к ревьюеру.

## 🚨 Критические требования (Автотесты и ревью)
*Без соблюдения этих требований проект не пройдёт автоматическое тестирование.*

### Отображение в браузере
- [ ] Проект визуально соответствует макету: все секции, блоки и элементы корректно отображаются в Firefox, Google Chrome или Yandex Browser.
- [ ] Отличие от макета не более 10% (для системы скриншот-проверки).
- [ ] Отличие не более 5px по вертикали и 3px по горизонтали (для проверки ревьюером).
- [ ] Использовать плагин Pixel Perfect для доводки вёрстки.
- [ ] Сетка макета не сбита (при сжатии страницы сохраняется расположение элементов, содержимое не выпадает за пределы блока, блоки не наезжают друг на друга).
- [ ] Отсутствует горизонтальная прокрутка и другие лишние полосы прокрутки при ширине экрана >= минимально допустимой.
- [ ] Свёрстаны состояния `:hover` и `:active` для интерактивных элементов.

### Рекомендации к текущему проекту (Функциональность и позиционирование)
- [ ] Вёрстка не вредит функциональности JS:
  - [ ] Карточки появляются во всех предусмотренных ситуациях.
  - [ ] Работают прелоадеры и заглушки ошибок.
  - [ ] Работает поиск.
  - [ ] Видеоролики подставляются в основной блок по клику.
- [ ] `position: absolute` в CSS используется **только** для блока `.visually-hidden`.
- [ ] Остальной лейаут выполнен с применением гибких раскладок (flex/grid).
- [ ] Изображения и видео подогнаны под заданные размеры через `object-fit`.
- [ ] Состояния выбранных чекбоксов реализованы через псевдоэлементы.
- [ ] Подчёркивание у кнопок и чекбоксов появляется при наведении на всю активную зону (включая сам чекбокс), а не только на текст.

## 🎨 CSS

### Форматирование кода
- [ ] Между селекторами и открывающими скобками стоит пробел.
- [ ] Каждое правило начинается с новой строки.
- [ ] Стоят точки с запятой.
- [ ] Закрывающие скобки вынесены на отдельную строку.

### Именование классов
- [ ] Выбраны подходящие по смыслу имена.
- [ ] Отсутствует слитное написание слов.
- [ ] Единообразное разделение слов (только `kebab-case` или только `camelCase`).
- [ ] Нет транслитерации и необщеупотребительных сокращений.
- [ ] Использованы имена классов из брифа (если применимо).

### Базовые стили и типографика
- [ ] У `body` и типовых элементов сброшены браузерные отступы.
- [ ] Для всех элементов корректно заданы: цвета фона, размеры, межстрочные и межбуквенные расстояния, расстояния между словами (при необходимости).
- [ ] Шрифты подключены в правильном порядке (от современных к старым с указанием формата).
- [ ] Указаны альтернативные шрифты.
- [ ] Семейство, вес, начертание и размеры шрифтов соответствуют макету.

### Лейаут и позиционирование
- [ ] Для организации лейаута ключевых блоков использован `flex` или `grid`.
- [ ] Корректно отцентрированы необходимые элементы.
- [ ] Не задана фиксированная высота/ширина там, где можно использовать `min`/`max` или гибкость (блок должен растягиваться при добавлении текста).
- [ ] Абсолютное позиционирование используется только там, где нельзя применить статичное или относительное.
- [ ] Контекст позиционирования указан корректно (например, `position: relative` у нужного родителя).
- [ ] Корректно задан `z-index` (нет спрятавшихся элементов).

### Качество кода
- [ ] Нет пустых CSS-правил.
- [ ] Нет дублирующихся селекторов.
- [ ] Нет дублирующихся свойств внутри CSS-правил.
- [ ] Стили одинаковых элементов не дублируются, а переиспользуются.
- [ ] Не используются инлайновые стили в HTML.

## ✨ Хорошие практики (Рекомендуется для портфолио)
*Необязательны для сдачи, но улучшают качество кода.*

### HTML и разметка
- [ ] В разметке нет лишних обёрток `<div>`.
- [ ] У ссылок нет пустых атрибутов `href`.
- [ ] У всех изображений задан атрибут `alt` с описанием на языке страницы.
- [ ] Всем изображениям заданы ограничения размеров.
- [ ] Элементам не добавлены классы, которые не используются.
- [ ] В стилях не указаны неработающие свойства (например, размеры для строчных элементов).

### CSS и геометрия
- [ ] Для всех элементов переопределено дефолтное значение `box-sizing`.
- [ ] Внутренние отступы задаются через `padding`.
- [ ] Нет лишних отступов у первых и последних элементов в списках и блоках с абзацами.
- [ ] Flex/grid не применяются без необходимости.
- [ ] Для отступов между элементами использован `gap` вместо `margin`.
- [ ] Нет чрезмерной стилизации (например, дублирование размеров для обёртки и картинки).
- [ ] Интерлиньяж задан в относительных единицах.
- [ ] В элементах формы используются `inherit` или `currentColor`.
- [ ] Для предсказуемого поведения инпутов использован `appearance: none;`.
- [ ] Вместо `overflow: scroll` использован `overflow: auto`.
- [ ] Вид курсора меняется при наведении на интерактивные элементы.
- [ ] Для позиционирования изображения задано `object-position` вместе с `object-fit`.
- [ ] Для стилизации интерактивных элементов используется `outline`, а не `border`.
- [ ] CSS-правила расположены в примерном соответствии с позицией элементов в DOM.

### Доступность и состояния
- [ ] Для стилизации используются только селекторы классов, псевдоэлементов и псевдоклассов (кроме сбросов).
- [ ] Все элементы доступны при навигации с клавиатуры и визуально выделены (`:focus` и `:focus-visible`).
- [ ] Учтены особенности `:focus` и `:focus-visible` (например, в `:focus-visible` у элементов формы лейбл обводится, а в `:focus` — нет).

### БЭМ (если используется в проекте)
- [ ] Единообразное разделение имён блоков, элементов и модификаторов.
- [ ] Элемент не используется вне своего блока.
- [ ] Нет элементов элементов (например, `block__elem1__elem2`).
- [ ] Класс модификатор не используется без указания блока или элемента.
- [ ] Классы модификаторы описывают только модифицированное значение.
- [ ] Внешняя геометрия блоков задана через миксы.
