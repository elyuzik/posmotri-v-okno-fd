- [ ] **Изучить HTML:** Не менять заданные имена классов и существующую CSS-стилизацию из заготовки.
- [ ] **Минимизировать правки HTML:** Текущего HTML достаточно для выполнения задачи.
- [ ] **Изучить `<template>`:** В конце `<body>` находятся 4 шаблона (карточка видео, прелоадер, кнопка «Показать ещё», блок с ошибкой). Они используются для создания интерактивности на JS.
